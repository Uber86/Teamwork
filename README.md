# Сервис рекомендаций кредитного продуктов
https://github.com/Uber86/Teamwork

## О проекте

Микросервис для персонализированных рекомендаций кредитных продуктов клиентам банка через:
- Мобильное приложение
- Личный кабинет
- Telegram-бота

**Главная цель**: Оптимизация процесса подбора кредитных продуктов для клиентов с целью повышения удовлетворенности и увеличения продаж

## Быстрый старт

### Требования
- Java 17+
- PostgreSQL 14+
